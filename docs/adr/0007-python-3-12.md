# 0007. Фиксируем Python 3.12

- **Дата:** 2026-10-16
- **Статус:** Accepted
- **Контекст задачи:** инфраструктура проекта

## Контекст

На машине разработки установлен Python 3.14.7, при этом ключевые зависимости
(`torch`, `vLLM`, `ctranslate2`/`faster-whisper`) могут не иметь готовых колёс для
3.14 и требовать сборки/патчей. Нужна версия с гарантированной совместимостью.

## Рассмотренные варианты

1. **Python 3.12** — зрелые колёса для всего стека, минимум сюрпризов.
2. Python 3.14 — новее, но риск отсутствия колёс и несовместимости в самом
   чувствительном месте (ML-стек).

## Решение

Мы фиксируем **Python 3.12** в `pyproject.toml` (`requires-python = ">=3.12,<3.13"`)
и создаём виртуальное окружение через `uv python`. Это отдельно от системного
3.14.

## Последствия

- Положительные: предсказуемая установка зависимостей, меньше времени на отладку
  сборки.
- Отрицательные: не используем новейшие синтаксические возможности 3.13/3.14 —
  для проекта это несущественно. Обновление версии — отдельным ADR.
