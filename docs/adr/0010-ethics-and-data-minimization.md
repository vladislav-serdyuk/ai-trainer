# 0010. Этика, дисклеймер, минимизация ПДн

- **Дата:** 2026-10-16
- **Статус:** Accepted
- **Контекст задачи:** раздел «Работа с данными и этика»

## Контекст

Задание прямо требует: использовать только открытые источники с корректным
указанием, не собирать персональные данные без необходимости, а бот должен
сообщать, что рекомендации носят информационный характер и не заменяют
официальные требования. Аудитория — 15–20 лет, часть пользователей
несовершеннолетние, что повышает требования к аккуратности.

## Решение

1. **Дисклеймер** добавляется к каждому содержательному ответу: рекомендации носят
   информационный характер и не заменяют официальные требования вузов и
   работодателей.
2. **Согласие при первом запуске** на основе `legal_texts/` (политика
   конфиденциальности `pp.md`, EULA `eula.md`); без согласия бот не ведёт диалог.
3. **Минимизация ПДн**: храним только `telegram_id` и историю сессий; не собираем
   лишнее; команда `/delete` удаляет историю пользователя.
4. **Источники** в базе знаний хранятся с указанием авторства/лицензии; ответы
   цитируют источники.

## Последствия

- Положительные: соответствие требованиям задания, снижение юридических рисков.
- Отрицательные: дисклеймер в каждом ответе — чуть больше текста; удаление данных
  усложняет аналитику (для категории Senior она не требуется).
- Вне рамок: полный compliance-аудит. Тексты в `legal_texts/` — заготовки для
  прототипа, их финальную форму согласуют отдельно.
