# 0006. Веб-поиск через duckduckgo_search за абстракцией

- **Дата:** 2026-10-16
- **Статус:** Accepted
- **Контекст задачи:** этап 2 (информационный режим), живой поиск «желательно»

## Контекст

Информационный режим выигрывает от свежих данных из интернета. Для прототипа
нужен поиск без API-ключей и лишних договоров.

## Рассмотренные варианты

1. **duckduckgo_search** — без ключей, быстрый старт, подходит для прототипа;
   минусы: нестабильность выдачи и возможные лимиты.
2. Поисковые API (Google/Bing/SerpAPI) — стабильнее, но требуют ключей и денег.

## Решение

Мы используем **duckduckgo_search** как инструмент `web_search` за интерфейсом
`SearchProvider`. Поиск — только **дополнение** к RAG, всегда с цитированием
источника. При недоступности сервиса бот продолжает работать на базе знаний
(fallback), не выдавая ошибок пользователю.

## Последствия

- Положительные: нет внешних зависимостей и ключей, изоляция за интерфейсом
  позволяет позже подключить платный провайдер.
- Отрицательные: нестабильность выдачи/лимиты — снижаем fallback'ом и тем, что
  смысловой основой остаётся KB, а не поиск.
