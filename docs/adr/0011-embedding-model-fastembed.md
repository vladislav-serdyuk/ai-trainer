# 0011. Модель эмбеддингов и реранкера через fastembed

- **Дата:** 2026-10-16
- **Статус:** Accepted
- **Контекст задачи:** этап 1–3, RAG, уточняет [ADR-0005](0005-rag-pgvector.md)

## Контекст

Для RAG нужны модель эмбеддингов и (опционально) реранкер. Изначально в
[ADR-0005](0005-rag-pgvector.md) как пример указан `multilingual-e5-small`.
Ограничения: 6 GB VRAM и желание не тянуть `torch` ради CPU-инференса.

## Рассмотренные варианты

1. **sentence-transformers + `multilingual-e5-small`** — точное соответствие
   исходному документу, но тянет `torch` (тяжёлая зависимость).
2. **fastembed (ONNX) + `intfloat/multilingual-e5-large`** — есть в fastembed, но
   dim 1024 и вес ~2.24 GB, избыточно для прототипа на слабом железе.
3. **fastembed (ONNX) + `sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2`**
   — dim 384, ~0.22 GB, многоязычная, без `torch`.

Проверка: в fastembed нет `multilingual-e5-small`, есть только e5-large.

## Решение

Мы используем **fastembed** (ONNX, без `torch`) с моделью
`sentence-transformers/paraphrase-multilingual-MiniLM-L12-v2` (размерность 384).
Реранк — опционально, через fastembed-модель `BAAI/bge-reranker-v2-m3`
(с 2026-10-19 включён int8-вариант `BAAI/bge-reranker-v2-m3-int8`: 0.57 GB
вместо 2.27 GB из-за места на диске).
Размерность совпадает с исходными 384, миграция схемы не требуется.

С 2026-10-20 реранкер используется **дважды за запрос**: для кандидатов KB
(`top_k*2` из SQL) и для очищенной веб-выдачи перед отбором top-5 в контекст
(см. [ADR-0006](0006-web-search-duckduckgo.md)). Это одна модель и разные наборы
пассажей — дополнительной памяти не требует, батч-инференс остаётся дешёвым.

## Последствия

- Положительные: лёгкая установка, инференс на CPU, совместимо с 6 GB; MULTI-
  язычность сохраняется.
- Отрицательные: это уточнение модели из ADR-0005 — качество e5-large выше, но
  несоразмерно тяжелее. При переезде на серверную GPU модель можно усилить
  (e5-large), размерность изменит `vector(dim)` — отдельная миграция.
- Источник истины — конфиг (`EMBEDDING_MODEL`, `EMBEDDING_DIM`); код зависит от
  интерфейса, а не от конкретной модели.
