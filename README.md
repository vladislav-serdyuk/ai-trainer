# AI-тренажёр для абитуриента и стажёра

Чат-бот (Telegram) в роли опытного наставника: задаёт проблемные кейсы по выбору
вуза, поиску работы и первому месяцу в компании, разбирает ответы и даёт
персональную обратную связь на основе базы знаний из открытых источников.

## Возможности

- **Справочник** — вопрос текстом или голосом; ответ по своей базе знаний (RAG,
  pgvector) и живому веб-поиску, с обязательным перечнем источников.
- **Тренажёр** — проблемный кейс → разбор твоего ответа: оценка 0–100, вердикт,
  что улучшить, удачный пример и типовые ошибки из каталога (11 ошибок).
- **Три сценария**: выбор вуза/колледжа, поиск первой работы, первый месяц в компании.
- **Голос**: распознавание через faster-whisper.
- **Всё локально**: LLM (Qwen2.5 7B через Ollama), эмбеддинги и реранк — без
  облачных API; веб-поиск — единственный внешний канал.

## Пример диалога

Реальные ответы из E2E-прогона (тренажёр, сценарий «Выбор вуза»):

```text
Ты собираешься поступать, но не понимаешь, кем хочешь работать.
Родители советуют «престижную» специальность, а ты не уверен. Как разберёшься?

> Я спрошу у родителей, какая специальность престижная, и поступлю туда.

🟡 В основном верно
Оценка: 40/100

Вот что можно улучшить:
Добавь анализ своих интересов и рынка труда вместо полного зависимости
от советов родителей.

Вот удачный пример ответа:
Сначала разберу, что мне интересно и к чему у меня склонности, потом
посмотрю статистику по вакансиям и зарплатам. Составлю список из
нескольких направлений и попробую каждое через курсы, беседы со
специалистами или короткую практику — так выбор будет моим.

Типовые ошибки, которые заметил:
- Выбор вуза или профессии только по престижу или совету окружающих
без анализа своих интересов и рынка труда

Источники:
1. Как выбрать профессию и вуз: треугольник «хочу — могу — надо» — rg.ru
2. Бюджетные места, целевое обучение и меры поддержки студентов — trudvsem.ru
```

Справочник отвечает так же — с перечнем проверенных источников:

```text
Источники:
1. Как проверить вуз перед поступлением: лицензия и аккредитация — obrnadzor.gov.ru
2. Как выбрать профессию и вуз: треугольник «хочу — могу — надо» — rg.ru
```

## Требования

- **GPU** Рабочая модель — `qwen2.5:7b` (~4.9 GB VRAM).
- **Docker + Docker Compose** (для контейнерного запуска).
- **NVIDIA Container Toolkit** нужен только для запуска в Docker с GPU.

## Быстрый старт

### Через Docker Compose

Все сервисы (БД, Ollama, миграции, сид-данные, инджест базы знаний и бот)
поднимаются одной командой:

```bash
cp .env.template .env              # указать TELEGRAM_BOT_TOKEN
docker compose up -d --build
```

### Вручную (локально)

Шаблон `.env.template` настроен на Docker Compose. Для локального запуска
поменяйте в `.env`: `DATABASE_URL` → `localhost:5433` и `LLM_BASE_URL` →
`http://localhost:11434/v1`. Также нужна установленная Ollama на хосте:

```bash
uv sync
cp .env.template .env              # указать TELEGRAM_BOT_TOKEN
docker compose up -d db
uv run alembic upgrade head
uv run python -m ai_trainer.repository.seed
uv run python -m ai_trainer.rag.ingest
uv run python -m ai_trainer.bot.main
```

### CLI-тестер бота (без Telegram)

Прогнать диалог можно текстовым CLI внутри контейнера — без токена и VPN:

```bash
printf '1\n/start\n' | docker compose run --rm --no-deps -T bot \
  python tools/bot_cli.py --user 42
```
